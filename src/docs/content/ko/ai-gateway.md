# AI Gateway

외부 LLM 프로바이더나 Workers AI를 프런트엔드나 백엔드에서 직접 호출하는 설계는 운영 단계에 접어드는 순간 취약점이 드러난다. 상위 API의 갑작스러운 장애, 동일 프롬프트에 대한 중복 요청으로 인한 비용 낭비, 그리고 악의적인 사용자의 과도한 토큰 소비. 이 모든 것을 애플리케이션 코드 측의 개별 로직으로 감당하는 데는 한계가 있다.

AI Gateway는 모델 호출 **직전에 배치하는 리버스 프록시**이다. 추론 처리 자체는 수행하지 않으며, OpenAI, Anthropic, Google Gemini, Workers AI로 향하는 통신을 일원화하여 중개함으로써 관측 가능성과 비용 방어벽을 제공한다.

## 제공되는 5가지 방어벽

1. **요청 로그**: 기본적으로 프롬프트, 응답, 프로바이더, 모델, 토큰 수, 비용, 소요 시간을 대시보드에 기록한다. 누가 호출했는지 구분하려면 커스텀 메타데이터(요청당 5개까지)에 `user_id` 등을 붙인다. 저장할 수 있는 로그의 양과 기간에는 상한이 있다.
2. **완전 일치 캐시**: 프로바이더, 엔드포인트, 모델, 인증 헤더, 요청 본문이 모두 일치하는 요청에는 Cloudflare의 캐시에서 응답을 반환한다. 캐시에 적중한 호출은 프로바이더로 전송되지 않으므로 토큰 과금이 발생하지 않고 왕복 통신도 줄일 수 있다. 기본값은 비활성이며 게이트웨이 설정에서 활성화한다. 의미가 비슷한 프롬프트에도 적용하는 시맨틱 캐시는 Cloudflare가 추가를 예정하고 있는 단계로, 아직 사용할 수 없다.
3. **레이트 리미트**: 게이트웨이 전체에 일률적으로 횟수와 간격(고정 윈도 또는 슬라이딩 윈도)을 정해 제한한다. 초과한 요청에는 429를 반환한다. 사용자별로 제한하려면 dynamic route(조건 분기와 제한을 넣을 수 있는 라우팅 기능)의 Rate Limit 노드에서 `metadata.user_id` 등을 키로 지정한다.
4. **재시도와 폴백**: 실패한 요청을 최대 5회까지 재시도할 수 있다(간격은 최대 60초, 백오프는 constant·linear·exponential). 우선 모델이 에러나 타임아웃으로 실패했을 때의 전환 대상과 순서는 dynamic route나 model alias(여러 모델을 하나의 이름으로 호출할 수 있게 하는 기능)로 직접 정의한다.
5. **지출 상한**: 고정 또는 롤링 기간 내의 누적 비용이 상한에 도달하면 게이트웨이는 429를 반환하고 요청을 차단한다. 프로바이더·모델·메타데이터(사용자 ID 등)별로 예산을 나눌 수 있다. 비용은 추정치이므로, 동시 요청이 몰리면 일시적으로 상한을 넘을 수 있다.

## 도입 방법

도입 시 특별한 SDK는 필요하지 않다. 기존 API 클라이언트나 `fetch` 호출 대상을 AI Gateway의 엔드포인트 URL로 교체하고, 게이트웨이의 인증 토큰을 `cf-aig-authorization` 헤더에 붙인다. 새로 만드는 게이트웨이는 인증이 필수이다.

```js
const response = await fetch(
  `https://gateway.ai.cloudflare.com/v1/${env.CF_ACCOUNT_ID}/${env.AI_GATEWAY_NAME}/anthropic/v1/messages`,
  {
    method: "POST",
    headers: {
      "content-type": "application/json",
      "x-api-key": env.ANTHROPIC_API_KEY,
      "anthropic-version": "2026-10-21",
      "cf-aig-authorization": `Bearer ${env.CF_AIG_TOKEN}`,
    },
    body: JSON.stringify({
      model: "claude-haiku-5-5",
      max_tokens: 256,
      messages: [{ role: "user", content: "Workers의 특징을 요약해 주세요." }],
    }),
  },
);
```

## 비용을 억제하기 위한 설계 원칙

- **기본값은 최소·최저가 모델로 고정**: 모든 요청에 최고 성능 모델을 할당하지 않고, 고도의 추론이 필요한 특정 기능에만 플래그로 전환한다.
- **입력 텍스트 길이 상한 검증**: 클라이언트에서 전송된 거대한 텍스트를 그대로 프로바이더로 보내지 않고, Workers 앞단에서 글자 수나 토큰 수를 제한한다.
- **캐시 생존 기간(TTL) 고려**: 같은 요청이 반복되고 실시간성을 요구하지 않는 용도에는 긴 캐시를 설정하여 엣지에서 즉시 답변하도록 한다.
