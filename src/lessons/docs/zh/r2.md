# R2（对象存储）

收到云基础设施账单的工程师，常会对某一项不禁叹息：**Egress（向外传输下载数据）计费**。无论存储本身的维护成本多低，每当大量图片或视频被下载时，网络传输费用就会像滚雪球一样激增。

Cloudflare R2 不收取这项下载数据传输费用。无论文件被读取多少次，从 R2 直接发出的传输量的计费均为零。

## KV 与 R2 的区别

| 比较维度 | Workers KV                                    | Cloudflare R2                           |
| -------- | --------------------------------------------- | --------------------------------------- |
| 最小单位 | 键值（文本/二进制）                           | 对象（完整文件）                        |
| 容量限制 | 1 个键最多 25MB                               | 1 个对象最多 5TB                        |
| 最佳用途 | 配置值、标志、短寿命缓存                      | 图片、视频、日志、备份归档              |
| 计费结构 | 读取、写入、删除、列表请求次数 + 存储数据容量 | 存储数据容量 + 操作请求次数（无传输费） |

## 开发中需掌握的规范

- 基本操作为 `put(key, streamOrBuffer)`、`get(key)`、`delete(key)`、`list({ prefix })`。
- 提取获取的对象正文时，根据用途区分使用 `.text()`、`.arrayBuffer()` 或处理流的 `.body`。
- 把大文件读入缓冲区会一次性占用 Worker 的内存。100MB 左右以内，可以把长度已知的 `ReadableStream`（带 `Content-Length` 的请求体，或 `FixedLengthStream`）传给 `put()`。更大的文件应使用分段上传（`createMultipartUpload()`）。
- 使用签名 URL（Presigned URL），终端用户的浏览器无需经过 Worker 的内存和带宽，就能直接向 R2 上传或下载文件。R2 绑定无法生成签名 URL，需要用 S3 兼容 API 的凭据（Access Key ID 和 Secret）来签名（例如 `aws4fetch`）。有效期最长 7 天，在浏览器中使用时还需要配置 CORS。不能用于自定义域名。

编辑器中的 `env.STORAGE` 通过 RPC 转发到真实的 R2，与生产环境的绑定不同。`put()` 保存字符串，`get()` 返回正文字符串（不存在则为 `null`），因此不能再调用 `.text()`。`list()` 接收前缀字符串（而不是 `{ prefix }`），返回由键和大小组成的字符串（例如 `lesson/hello.txt (37B)`）的数组。存储空间由所有用户共用。
