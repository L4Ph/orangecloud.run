# Durable Object を自分で書く

エディタのコードは `App` という名前の Durable Object クラスである。実行すると、あなたのクラスがこのサイトの Durable Object の子として起動し、`fetch()` が呼ばれる。

## 試すこと

1. そのまま何度か実行する。`memory` と `sqlite` が同じ数だけ増える。
2. コメントを 1 文字書き換えて実行する。コードが変わるとインスタンスが作り直され、**`memory` は 1 に戻る。`sqlite` は続きから増える**。

`memory` は退避やコード更新で消えるインメモリ状態、`sqlite` は `ctx.storage.sql` に書いた永続状態である。本番では、アクセスが約 10 秒途絶えたときにも `memory` は同じように消える。

## 仕組み

このサイトはあなたのクラスを直接 DO として登録しているわけではない。サイト側の DO が「親」になり、`ctx.facets.get()` であなたのクラスを **facet**（子）として読み込む。facet は親とは別の SQLite を持ち、あなたのコードは親のデータに触れない。コードを書き換えたときは `ctx.facets.abort()` で facet を止めて作り直す。ストレージは残るので、`sqlite` だけが続きから数えられる。

ネットワークは遮断され、CPU は 100ms までに制限される。
