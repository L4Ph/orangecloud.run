# Durable Object를 직접 작성하기

에디터의 코드는 `App`이라는 이름의 Durable Object 클래스이다. 실행하면 작성한 클래스가 이 사이트의 Durable Object의 자식으로 시작되고 `fetch()`가 호출된다.

## 해 볼 것

1. 그대로 몇 번 실행한다. `memory`와 `sqlite`가 같은 수만큼 늘어난다.
2. 주석을 한 글자 바꾸고 실행한다. 코드가 바뀌면 인스턴스가 다시 만들어져 **`memory`는 1로 돌아가고 `sqlite`는 이어서 늘어난다**.

`memory`는 퇴거나 코드 업데이트로 사라지는 인메모리 상태이고, `sqlite`는 `ctx.storage.sql`에 쓴 영속 상태이다. 실제 환경에서는 약 10초간 접근이 없을 때도 `memory`가 똑같이 사라진다.

## 동작 방식

이 사이트는 작성한 클래스를 DO로 직접 등록하지 않는다. 사이트 쪽 DO가 "부모"가 되어 `ctx.facets.get()`으로 작성한 클래스를 **facet**(자식)으로 불러온다. facet은 부모와 별개의 SQLite를 가지므로 코드가 부모의 데이터에 접근할 수 없다. 코드를 바꾸면 `ctx.facets.abort()`로 facet을 멈추고 다시 만든다. 스토리지는 남으므로 `sqlite`만 이어서 센다.

네트워크는 차단되고 CPU는 100ms로 제한된다.
