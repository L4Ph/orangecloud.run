# Workers AI

대규모 언어 모델이나 이미지 생성 모델을 백엔드에 구현하려 할 때 가장 큰 골칫거리는 GPU 인프라 확보와 종량제 비용의 폭주다. 전용 인스턴스를 임대하면 유휴 시에도 고정비가 계속 발생하고, 대형 AI API에 의존하면 토큰 과금과 통신 지연 시간이라는 이중고에 직면하게 된다.

Workers AI는 추론 서버 프로비저닝과 API 키 관리가 필요 없게 한다. Cloudflare가 전 세계 데이터 센터에 배치한 서버리스 GPU 클러스터에 대해, Workers 내에서 몇 줄의 코드를 호출하는 것만으로 직접 추론을 실행할 수 있다.

## 주요 모델의 특성 및 비용 비교

모델마다 입력과 출력의 토큰 단가가 다르다. 비용은 "입력 토큰 수 × 입력 단가 + 출력 토큰 수 × 출력 단가"로 정해지므로, 프롬프트가 긴 요약이나 RAG에서는 입력 쪽이, 출력이 긴 문장 생성이나 추론에서는 출력 쪽이 커진다. 예를 들어 `mistral-small-3.1-24b-instruct`는 입력 $0.351, 출력 $0.555(100만 토큰당)이며, 입력 2,000토큰·출력 200토큰이라면 비용의 약 86%가 입력이다.

| 모델명                                         | 주요 용도                   | 특징 및 비용 수준 (단가는 100만 토큰당)                                                                                |
| ---------------------------------------------- | --------------------------- | ---------------------------------------------------------------------------------------------------------------------- |
| `@cf/mistralai/mistral-small-3.1-24b-instruct` | 범용 대화, 요약, 번역       | 입력 $0.351, 출력 $0.555. 컨텍스트 128,000토큰, 함수 호출 지원                                                         |
| `@cf/ibm-granite/granite-4.0-h-micro`          | 경량 태스크, 함수 호출      | 입력 $0.017, 출력 $0.112. 극도로 저렴함. 일본어를 포함한 12개 언어를 공식 지원하지만 성능이 영어와 같다고는 할 수 없음 |
| `@cf/openai/gpt-oss-20b`                       | 논리 추론, 복잡한 사고 단계 | 입력 $0.200, 출력 $0.300. 추론 강도를 low / medium / high 중에서 선택 가능                                             |
| `@cf/baai/bge-small-en-v1.5`                   | 벡터 임베딩(영어)           | 영어 전용이며 입력 $0.020. 일본어 문서에는 `@cf/baai/bge-m3`($0.012)나 `@cf/pfnet/plamo-embedding-1b`($0.019)를 사용   |
| `@cf/openai/whisper`                           | 음성 트랜스크립션           | 음성 1분당 약 $0.0005                                                                                                  |

## 응답 포맷의 차이에 주의

모델마다 반환 객체의 형태가 다르다는 점에 주의가 필요하다.

`mistral-small-3.1-24b-instruct`처럼 결과 객체의 `.response` 속성에 문자열 자체를 직접 반환하는 모델이 있다. 한편 `gemma-4-26b-a4b-it`처럼 OpenAI 호환의 `.choices[0].message.content` 구조를 반환하는 모델도 있다. 어느 쪽인지는 모델마다 다르므로, 사용할 모델의 페이지에 있는 출력 스키마로 확인한다. 우선 `.response`를 반환하는 단순한 모델부터 시작하는 것이 가장 고민이 적다.

```js
const answer = await env.AI.run("@cf/mistralai/mistral-small-3.1-24b-instruct", {
  messages: [
    { role: "system", content: "일본어로 40자 이내로 간결하게 답해 주세요." },
    { role: "user", content: "Cloudflare Workers의 장점을 한마디로" },
  ],
  max_tokens: 80,
});

console.log(answer.response); // 생성된 텍스트 문자열
```

- 응답을 순차적으로 브라우저에 흘려보내고 싶은 경우에는 `{ stream: true }`를 지정하여 Server-Sent Events(SSE)로 처리한다.
- 요금은 Neuron(모델에 관계없이 GPU 연산량을 재는 단위)으로 청구된다. Workers Free와 Paid 어느 쪽이든 하루 10,000 Neuron까지는 무료이며, 초과분은 Workers Paid에서 1,000 Neuron당 $0.011이다.
- 프로덕션 운용에서는 무제한 호출로 인한 과금 사고를 방지하기 위해, 전단에 **AI Gateway**를 배치하고(`env.AI.run()`의 세 번째 인수로 `{ gateway: { id: "게이트웨이 이름" } }`을 전달) 캐싱과 속도 제한을 설정하는 것이 정석이다.
