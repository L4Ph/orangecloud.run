# Workers의 실행 모델

Worker는 **요청마다 한 번 호출되는 함수**입니다. `fetch(request, env)`의 반환값이 그대로 응답이 됩니다.

## 기억할 네 가지

1. **상태는 요청 사이에 보장되지 않습니다.** 전역 변수는 isolate가 재사용되는 동안만 남습니다. 유지하려면 KV / D1 / R2 / Durable Objects에 둡니다.
2. **파일도 소켓도 없습니다.** 바깥 세계로는 `fetch()`와 바인딩(`env.DB` 등)으로 나갑니다.
3. **CPU 시간으로 과금합니다.** 네트워크 대기나 `sleep`은 무료라서 "외부 API를 기다리는" 처리가 쌉니다.
4. **제한이 먼저 옵니다.** 메모리 128MB, CPU는 기본 30초(유료는 최대 5분), 동시 실행 수도 플랜에 따릅니다. 무한 루프는 자기 Worker를 죽입니다.

## 대략적인 제한

| 항목 | 무료 | 유료 |
| --- | --- | --- |
| 요청 | 10만/일 | 1,000만/월 + 사용량 |
| CPU 시간 | 10ms/요청 | 30초/요청 (최대 5분) |
| 메모리 | 128MB | 128MB |

"요청마다 깨끗한 방"이라는 이미지로 충분합니다. 상태가 필요해지면 다음 장으로.

```js
export default {
  async fetch(request, env, ctx) {
    // request / env(바인딩) / ctx(waitUntil 등)
    return new Response('hello');
  },
};
```
