# R2 (객체 스토리지)

S3 호환 객체 스토리지입니다. 결정적인 장점은 **전송(egress)이 무료**라는 점이라 이미지, 영상, 백업, 빌드 산출물을 두기에 좋습니다.

## KV와 R2 선택

| | KV | R2 |
| --- | --- | --- |
| 단위 | 키와 값(작음) | 객체(파일) |
| 크기 | 값 25MB | 객체 5TB |
| 어울림 | 설정, 캐시 | 이미지, 영상, 로그, 산출물 |
| 과금 | 읽기/쓰기 횟수 | 저장량 + 작업 횟수(전송 무료) |

## 기억할 것

- `storage.put(key, value)` / `get` / `delete` / `list`
- 가져온 객체는 `.text()`, `.arrayBuffer()`, `.body`로 읽음
- 큰 파일은 스트림을 `put`에 넘길 수 있음
- 서명된 URL을 발급해 브라우저가 직접 업로드/다운로드하게 하는 것이 정석

이 환경의 `env.STORAGE`는 실제 R2를 중계합니다(텍스트만).
