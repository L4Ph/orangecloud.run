# D1 (SQLite)

Cloudflare의 SQL 데이터베이스입니다. 내부는 **SQLite**라서 SQL을 배우기에 딱 좋은 규모입니다. 읽기는 복제본으로 분산되고 쓰기는 프라이머리로 모입니다.

## 우선 이 세 줄

```js
await env.DB.exec('CREATE TABLE IF NOT EXISTS notes (id INTEGER PRIMARY KEY, body TEXT)');
await env.DB.prepare('INSERT INTO notes (body) VALUES (?)').bind('hello').run();
const { results } = await env.DB.prepare('SELECT * FROM notes').all();
```

- 값은 `prepare(...).bind(...)`로 넘깁니다. 문자열 연결은 SQL 인젝션이므로 금지
- `exec`는 **줄바꿈으로 문장을 나누므로** 여러 줄 DDL은 깨집니다. DDL도 한 줄로 쓰고 `prepare(...).run()`을 사용
- 결과는 `all()`의 `{ results }`, 한 행은 `first()`

## 과금의 핵심

비용은 **읽은 행 수**와 **쓴 행 수**입니다. `WHERE`에 인덱스가 없으면 전체 스캔이고, 전체 스캔은 모든 행에 과금됩니다. `CREATE INDEX`를 아끼지 마세요.

| 작업    | 무료     | 유료            |
| ------- | -------- | --------------- |
| 행 읽기 | 500만/일 | 월 250억 포함   |
| 행 쓰기 | 10만/일  | 월 5,000만 포함 |

여기서는 실제 D1 바인딩이 그대로 샌드박스에 전달됩니다. `env.DB`는 프로덕션과 완전히 같은 API입니다.
