# R2（オブジェクトストレージ）

S3 互換のオブジェクトストレージ。**egress（外への転送）が無料**なのが決定的で、画像・動画・バックアップ・ビルド成果物の置き場として強いです。

## KV との使い分け

|          | KV                 | R2                            |
| -------- | ------------------ | ----------------------------- |
| 単位     | キーと値（小さい） | オブジェクト（ファイル）      |
| 大きさ   | 25MB / 値          | 5TB / オブジェクト            |
| 向くもの | 設定・キャッシュ   | 画像・動画・ログ・成果物      |
| 課金     | 読み書き回数       | 保存量 + 操作回数（転送無料） |

## 覚えること

- `storage.put(key, value)` / `get` / `delete` / `list`
- 取得したオブジェクトは `.text()`、`.arrayBuffer()`、`.body` で読む
- 大きいファイルは `put` にストリームを渡せる
- 署名付き URL を発行して、ブラウザから直接アップロード/ダウンロードさせるのが定番

この環境の `env.STORAGE` は本物の R2 を中継しています（テキストのみ）。
