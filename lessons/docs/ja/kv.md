# KV（Key-Value）

読みが速く、世界中のエッジに複製されるキーバリューストア。**書き込みは結果整合**（反映まで最大 60 秒）なので、カウンタや在庫のような「厳密さが要る」用途には向きません。

## 向いている用途

- 設定値、フィーチャーフラグ、リダイレクト表
- セッションのキャッシュ、OGP 画像のキャッシュ
- 書き込みが少なく読みが多いデータ

## 覚えること

- `get` / `put` / `delete` / `list`（prefix 付き）
- 1 キー 25MB まで、値は JSON で保存すると楽
- 一覧は `list()` で prefix 検索。全件スキャンは苦手
- 書き込み課金は読みより高い（$5/100万書き込み）

この環境の `env.KV` は本物の KV を RPC で中継したものです。`get/put/delete/list` の形は本番と同じなので、そのまま覚えて構いません。

```js
await env.KV.put('user:1', 'Alice');
await env.KV.get('user:1'); // 'Alice'
await env.KV.list('user:'); // ['user:1', 'user:2', ...]
```
