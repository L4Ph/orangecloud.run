# Durable Objects（DO）

**名前ごとに世界に 1 つだけ存在する**オブジェクト。その中に SQLite のストレージと、直列化されたメソッド呼び出しを持ちます。「同時に 2 つ存在しない」ことが保証されるので、カウンタ・在庫・チャットルーム・レート制限・調整役はこれで作ります。

## なぜ必要か

Workers はリクエストごとに別の isolate に載る可能性があります。グローバル変数は信用できない。そこで **`Counter.get('global')` という名前で 1 つの実体を呼び出す**のが DO です。呼び出しはその実体の中で 1 つずつ順番に処理されます。

## 覚えること

- `env.COUNTER` に名前を渡すと、その名前の実体のスタブが返る
- スタブのメソッドは RPC。戻り値はシリアライズ可能な値
- ストレージは SQLite（`ctx.storage.get/put`、SQL も可）
- `ctx.storage.setAlarm()` で「あとで起こして」ができる（リマインダー、バッチ）
- 使っていない間は課金されない（hibernation）

この環境の `env.COUNTER` は、実際にデプロイされた Durable Object です。**値は実行をまたいで残ります。** 何度か実行して増えていくのを確認してください。

```js
const n = await env.COUNTER.increment(); // 同じ名前なら同じ実体
await env.COUNTER.read(); // 保存された値を読む
```
