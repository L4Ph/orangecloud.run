# D1（SQLite）

Cloudflare 的 SQL 数据库。内部就是 **SQLite**，规模刚好适合学 SQL。读取分散到副本，写入汇聚到主库。

## 先看这三行

```js
await env.DB.exec('CREATE TABLE IF NOT EXISTS notes (id INTEGER PRIMARY KEY, body TEXT)');
await env.DB.prepare('INSERT INTO notes (body) VALUES (?)').bind('hello').run();
const { results } = await env.DB.prepare('SELECT * FROM notes').all();
```

- 用 `prepare(...).bind(...)` 传值。字符串拼接会导致 SQL 注入，禁止
- `exec` 会**按换行拆分语句**，多行 DDL 会被拆坏。DDL 也写成一行并用 `prepare(...).run()`
- 结果是 `all()` 的 `{ results }`，单行用 `first()`

## 计费的关键

费用来自**读取的行数**和**写入的行数**。`WHERE` 没有索引就是全表扫描，也就是为每一行付费。不要省 `CREATE INDEX`。

| 操作 | 免费 | 付费 |
| --- | --- | --- |
| 读取行数 | 500 万/天 | 每月 250 亿包含 |
| 写入行数 | 10 万/天 | 每月 5000 万包含 |

这里直接把真实的 D1 绑定交给沙箱。`env.DB` 与线上 API 完全相同。
