# R2（对象存储）

兼容 S3 的对象存储。决定性的优点是**出网流量免费**，因此非常适合放图片、视频、备份和构建产物。

## KV 与 R2 怎么选

|      | KV           | R2                            |
| ---- | ------------ | ----------------------------- |
| 单位 | 键与值（小） | 对象（文件）                  |
| 大小 | 单值 25MB    | 单对象 5TB                    |
| 适合 | 配置、缓存   | 图片、视频、日志、产物        |
| 计费 | 读写次数     | 存储量 + 操作次数（出网免费） |

## 要记住的

- `storage.put(key, value)` / `get` / `delete` / `list`
- 取回的对象用 `.text()`、`.arrayBuffer()`、`.body` 读取
- 大文件可以把流直接交给 `put`
- 生成签名 URL，让浏览器直接上传/下载是常见做法

本环境中的 `env.STORAGE` 中转真实 R2（仅文本）。
