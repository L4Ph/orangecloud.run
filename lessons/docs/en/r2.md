# R2 (object storage)

S3-compatible object storage. The decisive part is that **egress is free**, which makes it the obvious home for images, video, backups, and build artifacts.

## KV or R2?

|         | KV                    | R2                                 |
| ------- | --------------------- | ---------------------------------- |
| Unit    | key and value (small) | object (file)                      |
| Size    | 25MB per value        | 5TB per object                     |
| Good at | config, cache         | images, video, logs, artifacts     |
| Billing | read/write counts     | storage + operations (egress free) |

## What to remember

- `storage.put(key, value)` / `get` / `delete` / `list`
- Read a fetched object with `.text()`, `.arrayBuffer()`, or `.body`
- Large files can be streamed into `put`
- Mint a signed URL so the browser uploads and downloads directly

In this sandbox `env.STORAGE` proxies the real bucket (text only).
