# D1 (SQLite)

Cloudflare's SQL database. Under the hood it is **SQLite**, which is exactly the right size for learning SQL. Reads are distributed to replicas; writes go to the primary.

## Start with these three

```js
await env.DB.exec('CREATE TABLE IF NOT EXISTS notes (id INTEGER PRIMARY KEY, body TEXT)');
await env.DB.prepare('INSERT INTO notes (body) VALUES (?)').bind('hello').run();
const { results } = await env.DB.prepare('SELECT * FROM notes').all();
```

- Pass values with `prepare(...).bind(...)`. String concatenation is SQL injection, so don't
- `exec` **splits statements on newlines**, so multi-line DDL breaks. Keep DDL on one line and use `prepare(...).run()`
- Results arrive as `{ results }` from `all()`, or a single row from `first()`

## Where the bill comes from

You pay for **rows read** and **rows written**. A `WHERE` without an index means a full scan, and a full scan means you pay for every row. Do not skimp on `CREATE INDEX`.

| Operation    | Free     | Paid               |
| ------------ | -------- | ------------------ |
| Rows read    | 5M/day   | 25B/month included |
| Rows written | 100k/day | 50M/month included |

Here the real D1 binding is handed straight to the sandbox. `env.DB` is the same API as production.
