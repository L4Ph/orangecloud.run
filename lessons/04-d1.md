# D1（SQLite）

Cloudflare の SQL データベース。中身は **SQLite** なので、SQL を覚えるのにちょうどいい規模です。読み取りはレプリカに分散され、書き込みはプライマリへ集まります。

## まずはこの3つ

```js
await env.DB.exec('CREATE TABLE IF NOT EXISTS notes (id INTEGER PRIMARY KEY, body TEXT)');
await env.DB.prepare('INSERT INTO notes (body) VALUES (?)').bind('hello').run();
const { results } = await env.DB.prepare('SELECT * FROM notes').all();
```

- `prepare(...).bind(...)` で値を渡す。文字列連結は SQL インジェクションになるので禁止
- `exec` は**改行で文を分割する**ので、複数行の DDL を渡すと壊れる。DDL も `prepare(...).run()` で 1 行にするのが安全
- 結果は `{ results }`（`all()`）、1 行なら `first()`

## 課金の勘所

課金は**読んだ行数**と**書いた行数**です。`WHERE` に索引が無いと全行スキャン＝全行課金。`CREATE INDEX` を惜しまないこと。

| 操作 | 無料 | 有料 |
| --- | --- | --- |
| 行読み取り | 500 万/日 | 250 億/月まで込み |
| 行書き込み | 10 万/日 | 5,000 万/月まで込み |

この環境では本物の D1 バインディングがそのまま渡っています。`env.DB` は本番と完全に同じ API です。
